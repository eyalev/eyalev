I'm a software developer near Lisbon, Portugal. Mostly Python, Rust and TypeScript.

Most of what I build collects information that is scattered across a lot of places and keeps it attributed, so you can check where anything came from. [korrents](https://korrents.com) is a public belief journal: what people currently believe, when they said it, and what changed their minds. [ppll](https://ppll.app) gives each public figure one page of where they actually publish. [rcmnd](https://rcmnd.app) collects what named people recommend, every entry traced back to the post where they said it.

The rest is tooling for AI coding agents. The agents run in the terminal, and the terminal is a bad place to watch them from, close to impossible from a phone. [ttyview](https://github.com/ttyview/ttyview) streams tmux sessions to the browser as a cell grid instead of running a terminal emulator there, which is what makes it work on a phone. [mobile-cc](https://github.com/eyalev/mobile-cc) is that idea packaged for Claude Code. [cc-usage-json](https://github.com/eyalev/cc-usage-json) turns Claude Code usage into JSON you can script against.

I live in Portugal, so I also ended up writing some language learning tools. [How to Learn](https://howtolearn.app) is a directory of the best resources for learning any language, and [pt-variant](https://github.com/eyalev/pt-variant) tells you whether a YouTube video is European or Brazilian Portuguese.

Before that I worked mostly on Python backends and data pipelines, at Check Point and at BreezoMeter, which is now part of Google.

The rest here is a mix of small CLI tools. Some maintained, most written once for a specific itch.
